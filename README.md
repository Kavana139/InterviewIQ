# InterviewIQ — AI-Powered Mock Interview & Career Coach

## Problem
Students preparing for software engineering interviews usually practise
with generic question lists. These don't match their own resume, don't
adapt to their answers, and don't show which topics they are weak in.

## Solution
InterviewIQ is a web app that runs personalised mock interviews. The
student uploads a resume and picks a role. The app asks questions one at
a time, scores each answer with a fixed rubric, tracks performance by
topic, and recommends what to practise next.

## Core features
1. Resume-aware interview questions
2. Adaptive follow-up questions
3. Rubric-based feedback (correctness, clarity, relevance, completeness)
4. Weak-topic and progress tracker
5. Voice answers (optional, built last)

## Tech stack
React + Vite, Tailwind CSS, FastAPI, PostgreSQL, SQLAlchemy, LLM API,
PyMuPDF, Pydantic, Pytest
